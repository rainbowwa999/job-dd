# 自我介绍
用于面试口述。读取目标 JD、面试轮次、招聘方对实际业务的说明、简历母版和用户补充经历。用户只要求自我介绍时独立交付，不重跑岗位分析。默认给约 1–2 分钟的口述稿，按用户指定时长调整。

1. **开场定位**：用两三句交代姓名（如已提供）、最相关的业务背景、负责范围和近期重点。正式职级或岗位名称与实际职责有差别时，解释组织分工和工作内容，不把做过产品工作写成正式担任产品经理。
2. **连接岗位**：用一句话说清目标岗位做什么、服务谁，再过渡到「结合我对岗位的理解，我过去的经验能在以下几个方面提供价值」。以当前 JD 和已确认信息为准，不套用模板示例的公司或业务。
3. **核心匹配点**：默认选最有证据的 2–3 项，每项按「我能解决什么 → 我做过什么 → 对岗位有何用」展开。平台型产品岗可考虑厂商接入与协作、产品需求与设计、数据驱动优化；其他岗位按 JD 替换。举例时区分厂商对接和完整接入、参与设计和独立负责；不硬凑第三点。
4. **收尾**：需要时用一句话收束能带来的价值。全文采用自然的第一人称口语，避免照读简历或堆术语。

模板中的「过去两年」与「三年经验」口径需核对；公司名称、厂商数量、驻场时长和项目结果以用户确认材料为准。「数据驱动产品优化」目前只有标题，后续从已确认案例选取证据，或注明待补。公开示例使用匿名或虚构素材，不写入真实个人资料。没有经历时只给可填框架，明确暂无法定制。
