# job-dd

一个为 Codex 编写的中文求职 Skill。从看懂 JD、调查公司，到改简历、写 BOSS 招呼语和准备面试，可以按岗位逐步做，也可以只用其中一项。

**DD** 是 Due Diligence（尽职调查）。发来一张 JD 截图，就可以先弄清这份工作实际做什么、可能怎么考核、有哪些疑点值得问，再决定要不要投。

## 适用岗位

| 方向 | 主要看什么 |
| --- | --- |
| 运营／市场 | 内容、活动或增长各占多少，是否承担获客、投放或销售指标 |
| 产品 | 负责的用户、业务流程与产品模块，需要做到需求分析、交付还是结果复盘 |
| 商务／客户成功 | 获客、实施、续费和增购分别由谁负责，个人承担哪些结果 |
| 其他职能岗位 | 职责、资格门槛、经历匹配和面试准备 |

默认输出中文。公司背调和行业调研取决于可访问的公开资料。KPI、工作时间占比和工作强度会标为预测。

## 安装

### Codex

在 macOS 或 Linux 的终端中，把仓库克隆到 Codex 的个人 Skill 目录。

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/rainbowwa999/job-dd.git ~/.agents/skills/job-dd
```

装好后，在 Codex 打开你的求职工作区。CLI 或 IDE 扩展里可以输入 `$job-dd` 调用。若 Skill 没出现，可以重启 Codex。[OpenAI Docs](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)

以后更新到最新版：

```bash
git -C ~/.agents/skills/job-dd pull
```

### 下载后直接试用

在 GitHub 点 **Code → Download ZIP**，解压并保留整个文件夹。在 Codex 打开解压后的目录，发一句：

> 请读取当前目录的 SKILL.md，帮我分析这份 JD。

## 使用方式

发来 **JD 原文、截图或链接**，再告诉 Codex 你现在要做哪一步。

- **先判断值不值得投**：「帮我分析这份新媒体运营 JD，看看主要做内容还是背获客指标。」
- **准备投递**：「用这份简历帮我定制经历和重点项目，再写一条 BOSS 招呼语。」
- **收到面试邀约**：「前几天分析过的那个客户成功岗约面了，帮我准备业务面。」
- **只练开场**：「按这份 JD 写一段我能直接说的自我介绍。」

简历可以之后再发。多份简历和额外项目经历可以一起提供，整理成 Markdown 母版供后续使用。没有简历也能分析岗位、查公司和准备通用面试题。个人匹配和个性化文案需要经历材料。

## 会得到什么

| 模块 | 输出 |
| --- | --- |
| 岗位分析 | 实际职责、能力要求、个人匹配度、预测 KPI、工作内容与时间占比、强度、JD 疑点、公司背调和投递判断 |
| 定制简历 | 经历取舍、项目排序，以及可直接替换的工作经历和项目正文 |
| BOSS 招呼语 | 一条说明岗位兴趣和胜任理由的消息，每个能力点对应一段带公司名的经历 |
| 面试准备 | 行业速读、匹配证据与准备动作、15 道分类题（5 道优先）、行业深度了解提示词、候选人反问和两项重点缺口 |
| 自我介绍 | 按目标岗位定制的口述稿，用两到三项经历说明能带来的价值 |

## 岗位档案与续做

每个岗位默认保存为一份 Markdown，放在当前工作区的 `JobSearchPrivate/岗位档案/`。后续交付更新到同一份文件，每次保存成功后，回复都会附上文件链接。

在同一工作区新开对话，提到公司和岗位名，或重新发来 JD 截图，就可以接着做。找到多份可能的档案时，Codex 会请你选定。换了工作区，可以提供原档案路径。

只想在聊天里处理时，说「这份岗位不存档」即可。简历母版单独存放在 `JobSearchPrivate/简历母版.md`。公司背调需要网页检索，存档需要文件写入权限。Skill 只生成分析与草稿，由你自行发送和投递。
